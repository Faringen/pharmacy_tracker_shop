# Курсовой проект на тему "Разработка приложения для расчёта стоимости лекарств, нахождение аналогов в аптеках"

Курсовой проект написан на языке Java с использованием фреймворков **Spring boot и JavaFX**. Для хостинга локальной базы данных которая исползуется в проекте должен быть устоновлен Docker поледней версии

# Установка и запуск 
- Скачать репозиторий нажав кнопку «Code» и выбрать «Download ZIP»
- Распоковать его в любом удобном месте без кириллицы
- Устоновить Docker и выставить порт 8080
- Зайти в распакованную папку и запустить run.bat, в docker должен будет создатся контейнер с импользаванием образа PostgreSQL последней версии
- Ждать появления окна

## Для тестирования
- Открыть проект в программе IntelliJ IDEA и подождать пока подгрузятся пакеты
- После подгрузки открыть вкладку с Maven (буква M в правом трее)
- Раскрыть папку pharmacy-client и pharmacy-server
- В этих папка открыть папку Lifecycle и запустить в них test (с иконкой шестерни)
- Подождать как пройдет тестирование
